# Divinity-like

Прототип системы поверхностей в духе Divinity: Original Sin на Unity DOTS. Вода, масло, яд, огонь, электричество и пар лежат на клеточной сетке и реагируют друг на друга: огонь поджигает масло и яд, испаряет воду, электричество растекается по воде.

## Что реализовано

- **Клеточная симуляция на ECS.** Каждая клетка — сущность без трансформа и меша. Шаг симуляции выполняется двумя параллельными Burst-джобами с двойной буферизацией, поэтому результат не зависит от порядка обхода клеток.
- **Скорость распространения в метрах в секунду.** Интервал тика считается от размера клетки, так что плотность сетки не влияет на скорость огня и электричества.
- **Отрисовка одним мешем.** Пол — один Plane. Состояние сетки пишется Burst-джобом в текстуру (тексель на клетку), а шейдер сам смешивает соседние клетки, рисует неровные края и плавные переходы между типами.
- **Шейдер на HLSL под HDRP.** Копия HDRP/Lit с собственной функцией данных поверхности, без Shader Graph.
- **Интерфейс на Unity UI.** Панель выбора кисти, слайдер радиуса и строка состояния. Вёрстка адаптивная: Canvas Scaler, якоря, Layout Group, учёт safe area.
- **Инструменты редактора.** Пункты меню `Tools/Divinity` создают демо-сцену, пол и префаб интерфейса.

## Управление

| Действие | Ввод |
| --- | --- |
| Рисовать поверхность | ЛКМ |
| Вода / масло / яд / огонь / электричество | `1`–`5` или кнопки панели |
| Стереть | `0` |
| Радиус кисти | `+` / `−` или слайдер |

Электричество действует только на воду. Огонь на воде превращается в пар.

## Запуск

1. Unity `6000.3.25f1`.
2. Открыть сцену `Assets/OutdoorsScene.unity`.
3. Нажать Play.

## Структура

```
Assets/Scripts/Surfaces
├── SurfaceComponents.cs         компоненты ECS
├── SurfaceGridAuthoring.cs      настройки сетки и бейкер
├── SurfaceGridSpawnSystem.cs    создание клеток
├── SurfaceSimulationSystem.cs   шаг симуляции
├── SurfaceRules.cs              правила взаимодействия и внешний вид типов
├── SurfacePaintSystem.cs        ввод и кисть
├── SurfaceFloorRenderSystem.cs  передача состояния сетки в шейдер
├── UI                           панель кисти, кнопки, safe area
└── Editor                       сборка демо-сцены и префаба интерфейса
Assets/Surfaces/Shaders          шейдер пола
```

## Стек

Unity 6, Entities 1.4, Burst, HDRP 17, Input System, Unity UI.
